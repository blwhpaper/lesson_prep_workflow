# Assessment Design

## Skill purpose

Design closed-book examinations or projects using assessment-ready evidence.

## When to use

Only under an active assessment task after blueprint approval and L5 material availability.

## Required inputs

Task card, course SOT, outcomes, assessment policy, blueprint, L5 material IDs, scoring template, and security constraints.

## Required outputs

Assessment specification or items, source mapping, rubric/answer-key requirements, difficulty rationale, audit record, and release status.

## Forbidden actions

Do not use L0-L4 material in closed-book exams, invent facts or keys, expose protected sources, or release unaudited items.

## Fail-closed conditions

Missing L5 evidence, ambiguous correct answer, weak construct alignment, unknown copyright status, bias/accessibility concern, or absent moderation.

## Acceptance checks

Every item maps to outcome, blueprint, and L5 source; scoring is defensible; security and fairness checks pass; release has human approval.
