# Lesson Plan Generation

## Skill purpose

Generate a lesson plan from authorized, lesson-ready course material.

## When to use

Only under an active lesson-production task with approved L4 inputs and a course design contract.

## Required inputs

Task card, course SOT, learning outcomes, pathway, L4 material IDs, lesson template, duration, and accessibility constraints.

## Required outputs

A traceable lesson plan with timing, activities, evidence checks, optional-tool boundaries, alternatives, and source links.

## Forbidden actions

Do not use L0-L3 inputs as lesson content, generate directly from NotebookLM output, invent sources, or let AI/coding displace the course spine.

## Fail-closed conditions

Missing task authorization, insufficient L4 material, unclear outcome, unresolved source issue, or absent non-tool alternative where required.

## Acceptance checks

Every substantive element maps to outcomes and L4 IDs; timing is feasible; verification and accessibility are explicit; no source gate is bypassed.
