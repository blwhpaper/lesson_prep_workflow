# Course Instance Scaffold

Create a registered course directory containing:

```text
COURSE_SOT.md
COURSE_PLAN.md
COURSE_TASK_INDEX.md
COURSE_TASK_STATE.json
course.yml
SOURCES/
NOTEBOOKLM/
MATERIAL_DATABASE/
LESSONS/
PATHWAYS/
ASSESSMENTS/
STUDENT_TASKS/
AI_ACTIVITIES/
COURSE_DESIGN/
docs/
```

Assign a unique course ID and task prefix. Initialize course tasks as `not_started`. Replace generic placeholders with course-specific contracts only under an authorized task.
