# Course Expansion Protocol

1. Define a stable `course_id`, title, code, audience, and owner.
2. Register the course in `COURSE_REGISTRY.md`.
3. Copy the governed structure in `SHARED/templates/COURSE_INSTANCE_SCAFFOLD.md`.
4. Create course SOT, plan, index, state, and `course.yml`.
5. Assign a unique `TASK-<COURSE_CODE>-*` namespace.
6. Keep status `not_started` until an approved course task card is active.
7. Audit any imported material as new course intake.

Do not clone another course's content, assumptions, or assessments as defaults.
