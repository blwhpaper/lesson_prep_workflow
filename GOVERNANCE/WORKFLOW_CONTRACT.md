# Workflow Contract

## Control Hierarchy

Repository SOT and governance state authorize work; the course SOT and course state constrain course work; the active task card defines the executable scope.

## Stage Contract

Artifacts move forward only through documented review:

`intake -> audit -> grading -> adaptation -> lesson use -> assessment use -> reuse`

Each promotion must retain provenance, reviewer decision, maturity level, and unresolved risks. A downstream artifact may depend only on inputs permitted by the maturity model.

## State Changes

Update state, plan/index, changelog, and closeout consistently. Never infer task completion from file existence alone.
