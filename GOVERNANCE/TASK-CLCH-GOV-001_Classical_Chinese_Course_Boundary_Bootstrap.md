# TASK-CLCH-GOV-001 Governance Record

## Purpose

Bootstrap the course-boundary layer for `COURSES/classical_chinese` so later agents inherit stable scope, source, maturity, and anti-drift rules before any material extraction or lesson-design work begins.

## Result

This task establishes:

- the learner, course-shape, and translation-oriented identity of the standalone Classical Chinese course;
- a bounded source package rooted in the user-uploaded textbook set and future NotebookLM-assisted extraction workflow;
- a hard rule that NotebookLM output must lead first to a `16-session core material matrix`, not directly to lesson plans;
- a clear separation between Ancient Chinese knowledge ontology and later AI/vibecoding method-layer activities;
- fail-closed rules for course scope, copyright, maturity, and unauthorized output drift.

## Execution Notes

- This task is governance-only and does not claim that NotebookLM extraction has already been completed.
- The default repository course pointer remains outside this task's course line, so the task card itself supplies the governing course scope.
- `TASK-CLCH-GOV-001` closes the boundary bootstrap phase and routes the next executable work to `TASK-CLCH-MAT-001 | Knowledge Map Extraction`.

## Guardrails

1. No formal 16-week lesson-plan prose, slide deck, worksheet, assignment detail, or question bank may be generated in this task.
2. No long textbook excerpt may be copied into governance artifacts.
3. AI/vibecoding may appear only as downstream pedagogy-method framing, never as a substitute for disciplinary content.
4. Student CNKI prompt activity remains downstream lesson/activity design work and is not expanded here.
