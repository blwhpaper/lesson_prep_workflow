# Cross-Repository Reference Protocol

External repositories are closed by default. A task card must name the repository, allowed paths, purpose, and read-only status before access. Never write to, change state in, or copy domain-specific task semantics from another repository.

References may inform governance patterns, but repository names, task IDs, private data, trading semantics, and thesis-specific semantics must not leak into this repository. Record any approved reference in the task closeout.
