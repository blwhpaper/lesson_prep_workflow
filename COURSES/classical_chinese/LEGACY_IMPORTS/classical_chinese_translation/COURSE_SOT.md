# Course Source of Truth

## Identity

- 课程名称：古代汉语与翻译理解
- 课程对象：翻译专业本科生
- 课程周期：16周，每周2课时
- 课程定位：这不是中文系传统古代汉语通论课，也不是完整的典籍翻译课；它是面向翻译专业的古代汉语能力课。

## Course Spine

1. 古代汉语是知识主干。
2. 翻译判断是应用场景。
3. AI工具是辅助复核手段。
4. vibe coding / 数据化任务是可选辅助，不是课程主线。

- 王力《古代汉语常识》

- 郭锡良《古代汉语语法讲稿》

- NotebookLM 已上传资料
- 后续经人工确认加入的课程资料

Listing a source does not authorize public upload or classroom use without audit.

## Course Goals

1. 古文理解能力。
2. 译文判断能力。
3. AI译文解释能力。
4. AI解释复核能力。
5. 译法比较能力。
6. 论文观点验证能力。
7. 古籍证据链构建能力。
8. 原文、现代汉语还原、英文译文之间的结构化对齐能力。

## Prohibitions

1. 不直接写教案。
2. 不直接写16周大纲。
3. 不直接生成题库。
4. 不把 NotebookLM 输出当正式材料。
5. 不以 LLM 低级误译为主线。
6. 不让 AI 工具或 vibe coding 抢走古代汉语主线。
7. 不把文化制度项扩展成制度史课程。
8. 不强行凑数量。
9. 不编造出处。
10. 不使用未校勘材料做闭卷考试。
