# Legacy Classical Chinese Translation Import

This directory is the archived import of the retired standalone route `COURSES/classical_chinese_translation`.

It is not a formal course entry. The only formal Classical Chinese course route is `COURSES/classical_chinese`.

This directory exists only as quarantined legacy material pending future audit. Its files, including legacy governance files such as `COURSE_SOT.md`, `COURSE_TASK_INDEX.md`, and `COURSE_TASK_STATE.json`, do not define current repository or course source of truth.

Future `TASK-CLCH-MAT-*`, `TASK-CLCH-LESSON-*`, and `TASK-CLCH-ASSESS-*` work must not directly use or cite content from this directory unless the active task card explicitly authorizes legacy-material use and requires source audit first.
