# Contributing

1. Confirm the active repository task and course before editing.
2. Work from an approved task card and keep changes within its scope.
3. Preserve course isolation and put only mature cross-course patterns in `SHARED/`.
4. Record task state and index changes together.
5. Do not commit copyrighted source text or unreviewed generated output.
6. Run the task card's acceptance checks.
7. Prepare a closeout using `CLOSEOUTS/TASK_CLOSEOUT_TEMPLATE.md`.

Pull requests must identify the task, course impact, maturity changes, source audit status, and any human-review items.
